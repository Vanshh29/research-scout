# Research Scout

An autonomous research agent for the LLM agents / evaluation / RAG space. Every morning it ingests
new arXiv papers, GitHub repos, and blog posts, ranks them against an interest profile, builds a
vector store and knowledge graph, and delivers a brief — then measures its own quality with an
eval harness.

> Work in progress. See [`docs/PLAN.md`](docs/PLAN.md) for the architecture and build plan.
